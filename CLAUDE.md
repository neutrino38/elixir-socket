# elixir-socket

Ce fichier affine le référentiel IVèS. Il ne le contredit pas.

## Commits

Ne signe jamais un commit avec un trailer `Co-Authored-By`, quel qu'en soit
l'auteur. Les messages de ce dépôt ne portent que leur sujet et leur corps.

Pourquoi : ce dépôt est un fork dont les commits partent en merge request vers
`witchtails/elixir-socket2`. Un trailer que le projet amont n'emploie pas
détonne dans son historique.
